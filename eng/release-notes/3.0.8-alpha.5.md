# DripSharp.PdfCarton 3.0.8-alpha.5

Fix font initialization when `user.home` is empty: cache selection falls back to `java.io.tmpdir`, following Java 17 file behavior. Empty and malformed Java paths now survive internal construction until the relevant filesystem operation. Whitespace remains part of the pathname.

Existing public `System.IO.FileInfo` signatures are preserved. Exporting an internal Java path that .NET cannot represent throws `ArgumentException`; it is never replaced with another path or null.
